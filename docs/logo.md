# tangsu.me Logo

「糖酥旋纹」以三片折叠酥糖形成圆润旋涡，使用焦糖金、饼干金与奶油白，体现糖酥的个人气质。字标使用网页文字，让中英文说明和深浅色主题保持清晰。

使用内置图像生成工具制作。浅色模式采用奶油白背景版本，深色模式采用透明背景版本，让金色旋纹融入侧栏；跟随系统主题和手动切换均会自动更换图标。网页通过 CSS 设置圆角；尺寸变体仅使用 macOS sips 缩放。
